# Daily Bible Verse Website

## Overview
The **Daily Bible Verse** website displays a random Bible verse each day, along with a dynamic background image and popping emojis for an engaging user experience. This project is designed to provide spiritual inspiration in a visually appealing format.

---

## Features
1. **Daily Bible Verse**:
   - Fetches a daily Bible verse and reference using the [OurManna API](https://beta.ourmanna.com/api/v1/get/?format=json).
2. **Dynamic Background**:
   - Displays a random nature-themed background image fetched from Unsplash.
3. **Emoji Animations**:
   - Neon-styled emojis pop up on the screen during the loading sequence.
4. **Responsive Design**:
   - Fully responsive for mobile and desktop devices.
5. **Save Verse Button**:
   - Placeholder functionality for saving the displayed verse.

---

## Project Structure
```
├── index.html      # Main HTML file
├── styles.css      # Styling for the website
└── script.js       # JavaScript functionality
```

---


## Usage
1. **Open the website**:
   Load the `index.html` file in any modern browser.
2. **View the Verse**:
   Wait for the loading screen to fade out. The verse will be displayed along with its reference.
3. **Save the Verse**:
   (Feature under development) Click the "Save Verse" button to save the verse for later.


---

## Setup and Deployment
1. Clone the repository.
2. Ensure all files (`index.html`, `styles.css`, `script.js`) are in the same directory.
3. Open `index.html` in a browser to test locally.
